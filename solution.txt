Ammeter Testing & Analysis System

Overview
This project is a complete Ammeter testing, analysis, and visualization framework.
It simulates or collects measurements from multiple ammeters, analyzes their performance, and provides statistical comparison and a live dashboard.

The system includes:
    * Automated test execution
    * Statistical analysis (accuracy, consistency, error rate)
    * Visualization of current measurements
    * Streamlit dashboard for real-time results
    * Logging system for debugging and traceability

1. Installation:
pip install numpy pandas matplotlib streamlit pyyaml pytest
pip install -r requirements.txt
pytest -s --json-report --json-report-file=results/pytest_results.json

2. Running the system:
        python main.py
        pytest -s --json-report --json-report-file=results/pytest_results.json
        python -m src.run_analysis
        streamlit run ui/app.py

- python main.py
Runs the full end-to-end testing pipeline.
    * Executes the AmmeterTestFramework for all configured devices
    * Collects raw measurement samples from each ammeter
    * Computes statistical metrics (mean, median, std, min, max, etc.)
    * Runs the Orchestrator to normalize and process results
    * Saves final output to results.json
    * Generates and saves per-ammeter measurement plots
Output:
A complete execution of data collection + processing + visualization.

Execution Flow:
                AmmeterTestFramework
                        ↓
                Orchestrator
                        ↓
                AccuracyAssessment
                        ↓
                save_raw_plots()
                        ↓
                results.json generated

What happens:
    Loads all ammeters from config
    Runs sampling loop per device
    Collects raw measurements
    Normalizes results
    Saves plots per ammeter
    Outputs structured JSON file


- Pytest:
pytest -s --json-report --json-report-file=results/pytest_results.json
Runs all automated unit tests for the project.
    * Executes test suite for framework, analysis, and orchestrator logic
    * Prints live test output to the console (-s)
    * Generates a structured JSON test report
Saves results to: results/pytest_results.json
Output:
Validation report of system correctness (pass/fail per test).

Execution Flow:
                test_framework tests
                        ↓
                analysis tests
                        ↓
                orchestrator tests
                        ↓
                pytest_report.json

What happens:
    Validates:
        framework logic
        analysis correctness
        edge cases (empty results, failures)
    Ensures pipeline stability
    Generates structured test report


- Analysis:
python run_analysis.py
Runs only the data analysis phase on already collected results.
    * Loads existing measurement data
    * Computes statistical metrics:
    * mean
    * median
    * standard deviation
    * accuracy score
    * Ranks all ammeters by performance
    * Generates comparison tables
    * Saves output to analysis_results.json
Output:
Analytical results without re-running measurements.

Execution Flow:
                results.json
                        ↓
                AccuracyAssessment
                        ↓
                statistical computation
                        ↓
                ranking calculation
                        ↓
                analysis_results.json

What happens:
    Loads existing measurement data
    Computes statistical metrics
    Calculates accuracy scores
    Ranks ammeters
    Saves analysis output


- UI Dashboard:
streamlit run ui/app.py
Launches an interactive web-based dashboard.
* Loads processed JSON results
* Displays:
    Accuracy comparison table
    Performance ranking
    Measurement graphs (raw samples)
    Pytest results
    Analysis outputs
* Provides real-time visual inspection of system results
Output:
A fully interactive dashboard in the browser.

Execution Flow:
                results.json + analysis_results.json + pytest_results.json
                        ↓
                Streamlit UI layer
                        ↓
                charts + tables + plots

What happens:
    Loads all generated outputs
    Builds dashboard UI
    Displays:
    performance comparison
    raw signal graphs
    ranking results
    test validation results
